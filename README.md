# VAI-TTS-Server

A FastAPI-based Text-to-Speech (TTS) server built for generating speech with model selection.

## Features
* FastAPI backend for fast performance.
* Text-to-speech generation using Kokoro model by default.
* Simple endpoints for generating and requesting speech.

## Requirements
* Python 3.8+
* FastAPI
* Uvicorn
* Pydantic
